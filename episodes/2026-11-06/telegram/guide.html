OCCUPYSAAS

«Нас уволили. Мы пересобираем их SaaS»

Движение уволенных инженеров. Они собирают с помощью ИИ открытые копии дорогих сервисов — такие, чтобы ваш код работал с ними без переделок.

ZeroAuthy → вместо Auth0

Вход на сайт: логин, регистрация, Google и Microsoft, SMS, магические ссылки, MFA, роли и организации. Вышел v1.0.0-rc.1 — ранняя версия «на попробовать».

SalesCompel → вместо Salesforce

CRM: пока умеет компании и контакты (создать, изменить, найти). Ранняя стадия, для экспериментов.

ЛИЦЕНЗИЯ
Apache-2.0 — можно ставить у себя, в том числе в коммерческих проектах
ЦЕНА
0 ₽. Без оплаты за места, без телеметрии
ГДЕ
github.com/occupysaas · occupysaas.com
ДАЛЬШЕ
В очереди: базы знаний, трекер задач, фича-флаги, логи и мониторинг, поддержка клиентов. Цель можно предложить через issue на GitHub

Как они это делают: «чистая комната»

ИИ не копирует чужой код. Он строит сервис по публичному описанию, и это проверяется официальными библиотеками оригинала.

Доки
публичная документация API и стандарты
→
Спека
openapi.yaml: что сервис обязан уметь
→
Агенты
ИИ пишет код и тесты только по спеке
→
Проверка
SDK оригинала работает без правок
→
Релиз
у себя, свой сервер, свои данные
1

Только публичные материалы

Документация API, открытые стандарты (OAuth 2.0, OIDC, REST), поведение публичных SDK. Утёкший и закрытый код — запрещён.

2

Кто пишет спеку — не пишет код

Роли разделены. В каждом репозитории — правила CLEAN_ROOM.md и источник каждого примера.

3

ИИ-агенты строят, люди принимают

Сначала контракт API, потом код, потом тесты. Каждое слияние смотрит человек. Планы задач для агентов открыты: docs/plans, docs/superpowers.

4

Готово = старый код работает

Официальные SDK оригинала гоняют против нового сервера. Если ваш код надо переписывать — работа не закончена.

01 · СВОЙ СЕРВИС ВМЕСТО ПОДПИСКИ05
ПОПРОБОВАТЬ · 10 МИНУТ

Свой Auth0 на ноутбуке

Нужен только Docker. Одна команда (замените почту на свою):

docker run -d --name zeroauthy -p 8443:8443 \ -v zeroauthy-data:/data \ -e ZEROAUTHY_SERVER__LISTEN=:8443 \ -e ZEROAUTHY_SERVER__SYSTEM_HOST=localhost:8443 \ -e ZEROAUTHY_SERVER__TLS_SELF_SIGNED=true \ -e ZEROAUTHY_SERVER__TLS_SELF_SIGNED_CA_FILE=/data/ca.pem \ -e ZEROAUTHY_SECURITY__MASTER_KEY="$(openssl rand -base64 32)" \ -e ZEROAUTHY_BOOTSTRAP__ADMIN_EMAIL=you@example.com \ ghcr.io/occupysaas/zeroauthy:1.0.0-rc.1
1

Ссылка на первый вход администратора — в одноразовом файле, сервер пишет его при старте (путь — в логах: docker logs zeroauthy).

2

Проверка: https://localhost:8443/.well-known/openid-configuration — должен открыться JSON. Документация API — /docs.

3

Подключите своё приложение: в auth0-react, auth0-spa-js или nextjs-auth0 поменяйте домен Auth0 на свой сервер. Код менять не нужно — так заявлено в README.

ВАЖНО
  • MASTER_KEY сохраните отдельно: без него резервная копия базы бесполезна, сменить ключ нельзя.
  • Пока нет passkeys, WebAuthn и SAML. Это предрелиз — не для боевого сервиса.

01 · СВОЙ СЕРВИС ВМЕСТО ПОДПИСКИ06

Повторить метод для своего сервиса

Трекер задач, форма заявок, мини-CRM — всё, за что платите «за место». Работаем в Claude Code или другом ИИ-агенте для кода.

1

Выберите цель

У сервиса должна быть открытая документация API. Возьмите 3–5 функций, которыми реально пользуетесь, — не весь продукт.

2

Спецификация

Вот ссылки на публичную документацию API сервиса X. Составь openapi.yaml только для этих функций: […]. Каждое поле и ошибку подтверди ссылкой на документацию. Ничего не додумывай.
3

Сборка по спеке

Реализуй сервер строго по openapi.yaml. Сначала тесты на каждый эндпоинт, потом код, пока тесты не станут зелёными. Хранилище SQLite, запуск одной командой docker run.
4

Проверка совместимости

Подключите официальную библиотеку сервиса к своему серверу и прогоните реальный сценарий. Ломается — ошибку агенту.

ЧЕСТНО О РИСКАХ

Только публичные материалы — без чужого кода и утечек. Вход, безопасность и деньги — только после тестов и ревью человеком. Это не юридическая консультация.

GEMINI OMNI 1.2 FLASH

Ролик за $1: механика

ЧТО НОВОГО
Ролики до 15 секунд, лучше синхрон губ, правка обычным текстом. По данным Google — ~7 центов за секунду в API, то есть ~$1 за 15 секунд
ГДЕ
Без кода — приложение Gemini и Google Flow. Через API — Google AI Studio (бесплатного тарифа для этой модели нет)
Кадр
картинка в Nano Banana / Gemini
→
Оживить
«картинка → видео», 4–5 с на пробу
→
Править
текстом, по одной вещи за раз
→
Финал
10–15 с + пометка «ИИ»

Шаблон промпта

[Кто] в [где], [что делает]. Камера: [крупный план / пролёт / с руки]. Свет: [закат / неон]. Стиль: [документальный / кино / реклама]. Звук: [речь / музыка]. Длительность: 10 секунд.

Правки, которые работают

«сделай злее» · «сделай веселее» · «замени ночь на утро» · «пусть говорит медленнее» · «камера ближе к лицу»

Почему так дешевле: картинку можно перегенерировать сколько угодно, а секунды видео платные. Модель сильна именно в режиме «картинка → видео» — там она сразу вошла в топ слепых сравнений Arena.

ARSAZE + CLAUDE

Пишете «вырежи паузы» — видео режется

По тесту автора: ролик, который руками монтировали 3 ч 12 мин, с Claude собрали за 23 минуты. Бесплатно, если монтировать со своим ИИ.

Подключение за 5 минут

1

Регистрация на arsaze.com, загрузите видео.

2

Claude → Настройки → Коннекторы → «Добавить свой коннектор» → https://api.arsaze.com/mcp

3

Вход через OAuth, ключ не нужен. Работает также с ChatGPT и Gemini.

4

Откройте проект в браузере — правки видно вживую.

Команды

  • «Сначала составь план монтажа списком, потом применяй»
  • «Вырежи паузы длиннее 0,5 с и оговорки»
  • «Добавь субтитры: крупно, внизу, жёлтым»
  • «Найди, где я смеюсь, и собери нарезку на 30 секунд»
  • «Сделай вертикальную версию 9:16, лицо по центру»

04 · ФЕЙК ИЛИ НЕТ09

3 проверки за 2 минуты

1

Детектор Pangram

pangram.com/image-detector — 3 проверки в день без регистрации, с бесплатным аккаунтом 20 кредитов в день. JPG, PNG, WebP от 512×512 до 30 МБ, до 10 файлов сразу. Вердикт + тепловая карта: какие куски похожи на ИИ. Есть расширение для Chrome и Firefox.

2

Метки в файле

C2PA — «паспорт» файла: чем и когда сделан. Смотреть: contentcredentials.org/verify. SynthID — невидимая метка Google: загрузите картинку в приложение Gemini и спросите, сделана ли она ИИ. Pangram тоже показывает C2PA и EXIF, но решение принимает по пикселям.

3

Первоисточник

Google Lens или поиск по картинке: где она появилась впервые и кто выложил.

ЧТО ПОКАЗАЛ НАШ ТЕСТ
  • Скриншот и пересылка в мессенджере стирают метки — проверяйте оригинал.
  • Детекторы ошибаются на маленьких и пережатых картинках. 99,5–99,96% точности — цифры самой компании.
  • Вопрос «это правда?» сменился на «кто это сделал и зачем?». Главный детектор — голова.

Платить меньше

Kimi K3.1 Pro — открытая модель

2,8 трлн параметров, но на каждый запрос работает ~100 млрд («смесь экспертов») — поэтому дёшево. Окно ~1 млн токенов.

platform.kimi.ai — API совместим с OpenAI: меняете адрес и ключ. $2 за 1 млн токенов на вход, $10 на выход. Веса — huggingface.co/moonshotai.

Калькулятор за 10 минут

  • Выпишите все ИИ-подписки и API — сумма в месяц
  • Поставьте месячный лимит в консолях Anthropic, OpenAI, Google
  • Рутину — дешёвой модели, сложное — топовой

Агенту — почта и ключи

machinemail.dev — своя почта для агента. Дайте агенту machinemail.dev/auth.md и попросите тестовый ящик — без регистрации. Бесплатно: 3 000 писем в месяц. У каждого письма есть «отчёт о доверии», можно включить режим черновиков: агент пишет, отправляете вы.

5 правил ключей

1 · отдельная почта, не основная   2 · «только чтение», где можно   3 · оплата и удаление — после вашего «да»   4 · белый список адресатов   5 · раз в неделю журнал действий
