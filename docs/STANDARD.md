# Стандарт монтажа

Основа — «Конституция монтажа» (Игорь Брехов) + замечания Антона по пилоту 02.11. Пункты с ✔ проверяет `pipeline/qa.py` или `pipeline/cut.py`.

## Речь и резы
- ✔ Паузы между словами > 0,35 с ужимаются до ~0,2 с. Тишина по звуку (−38 дБ) > 0,9 с вырезается всегда — паузы ищем и по тексту, и по звуку (распознавание растягивает слова на тишину).
- Резать только в тишине, за 100–150 мс до слова. Кроссфейд звука 5–10 мс на каждой склейке.
- Берём последний полный дубль фразы. Фальстарты, «нет, нет», «вычёркиваем», служебные фразы — всегда вон.
- Бережный монтаж убирает 5–10 % длины выбранного; > 20 % — режется смысл (кроме записей со многими дублями).

## Взгляд (правило Антона)
- ✔ В кадре только взгляд в камеру. Взгляд в сторону/вниз ≥ 0,5 с (pipeline/gaze.py): без речи — вырезаем; во время речи — обязательно закрыть визуалом (вырезка статьи, скриншот, B-roll, графика), звук остаётся.

## Пустоты (правило Антона)
- ✔ Ни одного чёрного кадра, дыр и наложений. Кусок < 0,5 с — брак.
- Под интро и полноэкранной графикой всегда есть картинка (студия, вырезка), не чёрный фон. Интро уходит шторкой, открывая студию.

## Начало выпуска (правило Антона)
- Порядок: **тизер 5–10 с → интро → «привет, день N» → новости**.
- Тизер: нарезка из 3–4 самых цепляющих фраз ведущего из разных новостей этого выпуска (по 1,5–3 с), быстрые склейки, на каждой — вспышка визуала новости (логотип, цифра, кадр вырезки). Фразы выбираются из уже записанного, ничего не досъёмываем.
- Первая фраза тизера — самая сильная новость дня; последняя обрывается на интриге и уходит в интро.

## Ракурсы и темп
- Камера одна: кроп ×1,12–1,2 чередуется на склейках (~25 % времени), со сдвигом вниз (воздух над головой). План держится ≥ 3 с.
- Хук в первые 3–5 с. Картинка меняется каждые 5–15 с (YouTube), 1–3 с (Shorts/Reels). Ведущий в кадре ≥ 40 % времени.

## Визуал новостей
- К каждой новости — что показать: вырезка статьи с подсветкой фразы, скриншот поста X, логотип компании, цифра. Источник и дата в углу.
- B-roll 3–6 с, не больше 2–3 подряд, строго по смыслу фразы, звук стока выключен. Источники: свой B-roll (`_бренд/b-roll`), Pixabay (ключ `~/Downloads/transcribe/.pixabay_key`).
- Графика «показывает, а не пишет»: 1–3 слова. Вход 10–18 кадров ease-out, уход 8–12 кадров за край. Полноэкранная сцена 3–12 с.

## Звук
- Итог −14 LUFS, пик ≤ −1 dBFS. Музыка ~20 дБ тише голоса. Эффекты на пик движения (точность < 6 кадров).
- Интро: трек из `_бренд/музыка` (Pixabay Music), анимация в бит (`hyperframes beats`).

## Форматы
| | YouTube | Shorts | Reels |
|---|---|---|---|
| Длина | 10–20 мин | 15–60 с | 15–45 с |
| Кадр | 16:9 4K | 9:16 1080×1920 | 9:16 1080×1920 |
| Субтитры | отдельный .srt | вшиты, 2–4 слова, подсветка слова | вшиты, крупнее |
| Первый кадр | — | обложка: логотипы ИИ + плашка + заголовок | то же |
| Сборка | FCPXML → DaVinci | готовый MP4 | готовый MP4 |

## Бренд
Чёрный #0D0D0F, тёплый белый #F5F0E8, лайм #C8FF2E, красный «эфир» #FF3B30. Шрифты: Unbounded 800 (заголовки), Manrope 600/800 (текст), JetBrains Mono 700 (служебные подписи). Логотипы компаний — `graphics/logos` (LobeHub), только в новостном контексте.
