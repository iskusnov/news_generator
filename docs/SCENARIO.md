# Формат сценария v2 (с 04.11.2026)

Пишет Claude (утренняя задача 03:50 в проекте «Контент») сразу в финальном виде для чтения вслух (хуки, пометки шортсов, ТЗ обложек — бывшая работа Gemini), читает Антон. Решение Антона 03.11: не больше новостей, а понятнее и глубже — 5 историй для широкой аудитории YouTube, остальное бегущей строкой.

Вход: `выпуски/ГГГГ-ММ-ДД/01_новости/grok.md` на Drive (Grok, 03:30) + свой поиск (theneuron, techcrunch, The Verge, рассылки) + GitHub Trending.
Выход: `выпуски/ГГГГ-ММ-ДД/02_сценарий/scenario.md` на Drive (+ копия в проекте) и короткое сообщение Антону в тред до 05:00.

## Отбор
- 7–10 кандидатов, Антон на чтении берёт 5 (и может выкинуть любой).
- У каждого: **рубрика** (Люди и ИИ · Работа и деньги · Попробуй сам · Под капотом · Слухи), **для кого** (все · предприниматели · разработчики), **оценки 1–5**: понятно широкой аудитории / эмоция и вирусность / актуально через месяц.
- В рекомендуемой пятёрке: 3–4 разные рубрики, перевес «для всех», одна «Под капотом» (профессиональная, но объяснённая просто — как MIT «модель исправила веса другой модели без обучения»).
- Деньги и корпорации (IPO, отчёты, раунды) — только через «что это значит для нас» (готовятся к IPO → будут считать деньги → лимиты и цены).
- Предпочтение темам, которые будут искать и через месяц.

## Структура scenario.md
```
# Пока ты спал — ДД.ММ.ГГГГ, день N из 90
Рекомендуемая пятёрка: 1, 3, 4, 6, 8 (почему — 1 строка)

## Начало до заставки (записать один вариант)
А. «Сегодня в выпуске»: 3 самые сочные новости, по одной короткой эмоциональной фразе.
Б. Тизер с обрывом: самая интригующая история, фраза рвётся на вопросе («…и на чём же теперь зарабатывать?») — пауза.
(Если начало не записано, Claude соберёт его из первых фраз историй.)

## Привет
1–2 фразы: «Привет, это „Пока ты спал“, день N из 90…»

## Кандидат 1. <заголовок до 8 слов>
Рубрика · для кого · оценки 5/4/4 · 📍 Shorts? да/нет
**Хук:** одна фраза, ради которой остаются.
**Что случилось:** 2–3 простые фразы, без жаргона.
**Почему важно тебе (зрителю):** 1–2 фразы.
**Что делать:** попробовать / проверить / где нажать — ссылка уйдёт в описание.
**Панч:** шутка или живая реплика.
> Для тебя, не читать вслух: 2–3 строки контекста, чтобы понимать тему и отвечать в комментариях.
> Твоя позиция (выбери и скажи своими словами): А) «…это хорошо, потому что…» Б) «…настораживает, потому что…»
Источники: прямые ссылки (пост X, статья); скриншот: 01_новости/скриншоты/N.png
(слух — пометка «СЛУХ», реплика начинается с «Инсайдеры шепчут…»)

… кандидаты 2–10 …

## Вопрос дня
Один вопрос для закреплённого комментария, связан с самой спорной историей.

## Прощание
«Завтра в 6:00 я здесь. До встречи.» (после — улыбка 2–3 с под отбивку)

## Бегущая строка
10–15 строк «Кто — что, до 10 слов» + ссылка (на экран без ссылок, в описание со ссылками).
```

## В конце файла
- `[SHORT N | хук: … | почему: …] … [/SHORT N]` — 3–5 пометок прямо в тексте историй (кусок 20–50 с, понятен без выпуска, начинается с самой сильной фразы).
- ТЗ обложек: для выпуска (3 варианта под A/B) и для каждого шортса — текст крупно (до 4 слов), что в центре, какая эмоция ведущего (из библиотеки эмоций).
- 3 варианта названия «День N из 90: …» — с любопытством, конфликтом, эмоцией или цифрой, без обмана, до 70 символов.

## Правила текста
- Читается вслух за ~1,5 мин на историю, весь выпуск 8–12 мин.
- Короткие предложения: одно предложение — одна мысль; длинное — разбить на две фразы (Антон часто говорит фразу двумя кусками).
- Ничего не выдумывать: каждая цифра и цитата — со ссылкой. Слух — всегда слух.
