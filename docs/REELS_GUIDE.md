# Рилс / Shorts из своего видео: монтаж, субтитры, обложка

Руководство для тех, кто берёт этот репозиторий себе: как из записи «говорящей головы» получить готовый вертикальный ролик 9:16 с вырезанными паузами и оговорками, словесными субтитрами, плашками-цифрами, b-roll, звуком −14 LUFS и обложкой.
Так сделаны шортсы «Пока ты спал» и рилсы Toxic TV.

> Проще всего работать через **Claude Code**: откройте папку репозитория и напишите
> «Сделай рилс из `<файл>` по `docs/REELS_GUIDE.md`, хук — `<фраза>`». Claude сам пройдёт шаги ниже.
> Руками — тоже можно, всё запускается из терминала.

## 0. Что поставить (один раз)

| Что | Зачем | Как |
|---|---|---|
| ffmpeg | нарезка, склейка, звук | `brew install ffmpeg` (Mac) |
| Python 3.11+ | скрипты `pipeline/` | есть в системе / `brew install python` |
| Node 20+ и Playwright | рендер графики (HTML → кадры) | `cd graphics && npm i && npm i playwright && npx playwright install chromium` |
| Ключ Groq | распознавание речи по словам (Whisper Large v3, центы за час) | console.groq.com → API Keys; сохранить в файл, например `~/.groq_key` |
| (опц.) Python 3.12 + mediapipe | вырезать лицо для обложки | `python3.12 -m pip install mediapipe==0.10.14 opencv-python` |

Ключи и видео в репозиторий не кладём никогда.

## 1. Запись

Коротко — подробнее в `docs/RECORDING.md`:
- Камера на уровне глаз, свет спереди, петличка. Ошибся — пауза 2 секунды и повтор всей фразы: склейка возьмёт последний целый дубль.
- Горизонтальная 4K 16:9 удобна: из неё кадр 9:16 вырезается по центру, можно «панчить» (×1.12) на склейках. Вертикаль с телефона тоже подходит (`VERT=1`).
- Первая фраза — самая дерзкая (см. «Хук» ниже).

## 2. Звук, паузы, слова

```bash
ffmpeg -i ЗАПИСЬ.mov -vn -ac 1 -ar 16000 -c:a aac -b:a 48k audio.m4a
python3 pipeline/signals.py audio.m4a silence.json            # тишина [[start,end],…]
python3 pipeline/groq_words.py audio.m4a silence.json 0 words.json --key ~/.groq_key   # слова с таймкодами
```

`words.json` — каждое слово со временем начала и конца. Это основа и для монтажа, и для субтитров.

## 3. Монтаж: что берём

Создайте `takes.json` — куски исходника по порядку (секунды):
```json
{"fps": 25, "opener_after": null,
 "segments": [{"in": 12.4, "out": 18.9, "tag": "main"}, {"in": 31.0, "out": 44.2, "tag": "main"}]}
```
Правило выбора: из нескольких попыток берётся **последний целый дубль**; служебное («так, ещё раз») не берём. Порядок можно менять: самую острую фразу — в начало.
Через Claude: «прочитай words.json и собери takes на 45–60 секунд про `<тему>`, хук первым».

```bash
CUT_GAP=0.22 CUT_PAD=0.07 python3 pipeline/cut.py takes.json words.json silence.json - edl.json
```
`cut.py` режет паузы внутри кусков по словам (оставляет 0,22 с между фразами) и пишет монтажный лист `edl.json`.

## 4. Проверка до рендера (обязательно)

```bash
python3 pipeline/review.py edl.json words.json silence.json --audio audio.m4a draft.mp3 > review.txt
```
- `draft.mp3` — звук будущего ролика за секунды: послушайте склейки.
- В `review.txt` смотрите `ПОВТОР` (сказал дважды), `ОБРЫВ` (кусок режет слово), `ОБРЫВОК` (неудачный заход), `РАСТЯНУТО` (под словом спрятана оговорка — переслушать).
- Поправьте `takes.json` → снова шаг 3.

## 5. Субтитры и графика

Вся графика — HTML-шаблон, который рендерится в прозрачные кадры поверх видео:
- `graphics/overlays/shorts.html` — спокойный бренд: заголовок сверху, субтитры по словам ниже лица, карточки-цифры, логотипы, финальная карточка;
- `graphics/overlays/toxic_reels.html` — дерзкий стиль Toxic TV: капс-субтитры, штампы, «А vs Б».

Субтитры **ниже лица и выше зоны интерфейса** (нижние ~15 % экрана занимают кнопки Shorts/Reels). Сам текст — 1–3 слова на экране, текущее слово подсвечено.

**Спека ролика** (`spec.json`) — что и когда показывать. Её собирает скрипт из `edl.json` и `words.json`:
- в стиле Toxic TV: `reels_config.json` → `python3 pipeline/reels.py reels_config.json words.json`. Формат конфига — в шапке `pipeline/reels.py`.
- в стиле «Пока ты спал»: пример сборки — `episodes/2026-11-06/shorts_build.py`. Там словарь `FIX` (ошибки распознавания), `CARDS` (карточка на слове: «на слове “320” показать “4 из 320 000 000”») и `BR` (b-roll от слова до слова).

Рендер графики и упаковка с альфа-каналом:
```bash
cd graphics/overlays
TPL=shorts.html node render_vertical.js ../../spec.json ../../gfx --preview   # 3 кадра на проверку
TPL=shorts.html node render_vertical.js ../../spec.json ../../gfx            # все кадры
ffmpeg -framerate 25 -i ../../gfx/<id>/f%04d.png -c:v libvpx-vp9 -pix_fmt yuva420p -auto-alt-ref 0 -b:v 3M ../../gfx/<id>.webm
```

## 6. Сборка ролика

```bash
python3 pipeline/vertical_render.py edl.json spec.json ЗАПИСЬ.mov gfx/<id>.webm broll/ out/reel.mp4 > render.sh
bash render.sh          # или по шагам: bash render.sh 1, 2, 3
```
Что происходит:
1. Каждый кусок вырезается с точной длиной звука (иначе звук «уезжает»), кадр 9:16, чередование крупности.
2. Склейка без перекодирования.
3. Поверх — b-roll из папки `broll/` (окна из `spec.broll`), графика, звук до −14 LUFS.

Переменные: `VERT=1` — исходник уже вертикальный; `SRC2=… OFF2=1000` — второй файл записи (его время в edl = 1000 + t).
После правки монтажа перерендериваются только изменённые куски: имена кусков считаются по содержимому.

## 7. Обложка

- Кадр с эмоцией из записи: `ffmpeg -ss 12.3 -i ЗАПИСЬ.mov -frames:v 1 face.jpg`.
- Вырезать человека: `python3.12 pipeline/cutout.py face.jpg graphics/overlays/face.png`.
- Шаблон `graphics/overlays/shorts_cover.html` (1080×1920): варианты задаются параметром `?v=`; скопируйте любой блок `if(v==='…')` как образец.
- Снимок:
  ```bash
  npx playwright screenshot --viewport-size=1080,1920 "file://$PWD/graphics/overlays/shorts_cover.html?v=c5" cover.jpg
  ```

Правила обложки:
- 3–5 слов крупно: эмоция, интрига, парадокс. Цифры — так, чтобы читались без контекста («Всего 4 такси», а не «4 / 320 000 000»).
- Лицо с эмоцией, логотипы тех, о ком речь (`graphics/node_modules/@lobehub/icons-static-svg/icons`).
- **Название ролика не повторяет текст обложки**, а дополняет его фактами и поисковыми словами.

## Хук и структура (что реально работает)

- **Первые 3–5 секунд — самое дерзкое** из вашей речи: провокационный вопрос, шокирующая цифра, имена. Сдержанное начало проигрывает.
  Примеры: «Агенты никому не нужны?», «Бунт против подписок начался», «Хуанг, Маск и Хаксли — что общего?».
- 45–90 секунд, законченная история: хук → 3–5 фактов с плашками → вывод или панч.
- Картинка меняется каждые 1–3 секунды: смена крупности, карточка, b-roll.
- Доказательства (реальные ролики, посты, скриншоты) — b-roll поверх речи.
- Финальная карточка 3 с после последнего слова: куда идти дальше (полное видео, Telegram).
