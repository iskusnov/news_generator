# CLAUDE.md — как вести выпуск

> Уроки буткемпа (монтаж Zoom-уроков + лекция/ИИ-файл/ДЗ) — отдельный процесс: `bootcamp/README.md`.

Сначала прочитай `AGENTS.md` и `docs/STANDARD.md`. Темы, хуки и обложки сверяй с YouTube-радаром: `docs/RADAR.md`, последний отчёт — `docs/radar/`. Конвейер зафиксирован: не изобретай новые инструменты, меняй только через этот репозиторий.

## Окружение
- Облачный контейнер Claude: Python 3.13 (+3.12 с mediapipe==0.10.14 для gaze.py), Node 22, ffmpeg, Chromium (Playwright) — графика и анализ.
- Mac Антона через мост (`device_bash`, Linux-VM, лимит 180 с на вызов): исходники 4K, ffmpeg для нарезки шортсов/прокси. `$HOME/mnt/CloudStorage/GoogleDrive-tony.alexandridis@gmail.com/My Drive/News_generator` = папка Drive. Файлы в облаке без «Доступно офлайн» дают «Resource deadlock avoided» — попроси отметить папку выпуска офлайн или застейдж файл (`device_stage_files`).
- Ключи на Mac: `~/Downloads/transcribe/.groq_key_claude` (Groq), `~/Downloads/transcribe/.pixabay_key` (Pixabay). Никогда не выводить в чат.
- HyperFrames: `cd graphics && npm i`, `HYPERFRAMES_BROWSER_PATH=$(node -e "console.log(require('playwright').chromium.executablePath())")`.

## Рендер на Mac (с 03.11)
- Финальный рендер — нативный ffmpeg на Mac (VideoToolbox, ~2× реального времени в 4K), не в VM. Фоновая служба `com.pokatyspal.render` (pipeline/mac/watch.sh, ставится install.sh) раз в 20 с выполняет задания `~/PokaTySpal/queue/*.sh` по одному; логи `~/PokaTySpal/logs/<имя>.log` и `.rc`. Через мост папка видна как `$HOME/mnt/PokaTySpal`.
- Задание = bash-скрипт с абсолютными путями macOS (`$HOME/Library/CloudStorage/GoogleDrive-tony.alexandridis@gmail.com/My Drive/...`), ffmpeg из /opt/homebrew/bin. Итог — `05_публикация/…_FINAL.mp4`; после — кадры ФИНАЛЬНОГО файла проверить глазами.
- Условия: Mac на зарядке, не спит, приложение Claude открыто (мост).

## Шаги после записи (папка выпуска `выпуски/ГГГГ-ММ-ДД/`)
1. **Звук и прокси** (Mac): `ffmpeg -i ЗАПИСЬ -vn -ac 1 -ar 16000 -c:a aac -b:a 48k audio.m4a`; прокси для взгляда частями ≤120 с: `ffmpeg -ss X -t 120 -i ЗАПИСЬ -vf fps=5,scale=640:-2 -an proxy_X.mp4`. Застейджить.
2. **Распознавание**: Groq whisper-large-v3, `timestamp_granularities[]=word` и `segment` → `words.json` (см. pipeline/groq_transcribe.py; для слов добавить word).
3. **Сигналы**: `python3 pipeline/signals.py audio.m4a silence.json`; `python3.12 pipeline/gaze.py proxy_X.mp4 gaze_X.json --offset X` (склеить away).
4. **Дубли** (решаешь ты по сценарию из `02_сценарий` и тексту слов): `takes.json` — порядок кусков. Начало всегда: **тизер 5–10 с** (3–4 самые цепляющие фразы из разных новостей, по 1,5–3 с, tag `teaser`) → интро (`opener_after` = число кусков тизера) → привет и новости. Каждая новость = блок; служебное и брак не берём.
5. **Монтажный лист**: `python3 pipeline/cut.py takes.json words.json silence.json gaze.json edl.json`. Всё из `covers` закрыть визуалом новости.
5a. **Сверка до рендера (обязательно)**: `python3 pipeline/review.py edl.json words.json silence.json --audio audio.m4a draft.mp3 > review.txt`. Все ПОВТОР/ОБРЫВОК/ОБРЫВ исправить в takes; каждое РАСТЯНУТО переслушать — перераспознать 3–5 с вокруг через Groq (Whisper прячет «тьфу» и второй заход в одно длинное слово). **Сверку делаешь сам, «ок» Антона НЕ ждёшь** (решение Антона 04.11): по правилу «стоп» и повторов (docs/STANDARD.md) берёшь последний целый дубль, спорные места проверяешь сам (перераспознавание + огибающая звука −38 дБ) и сразу собираешь готовый ролик. Антону — готовый результат; в сдаче 1–3 строки «что решил сам» (если что-то не нравится — он скажет, перемонтируем).
6. **Графика** (начинать параллельно со сверкой; рендер плашек в 1080p, только ПОВЕРХ кадра с ведущим — без чёрных экранов; бегущая строка, ключевые слова, отбивка в конце): интро (`graphics/compositions/intro.html` + vars: день, дата, 3 главные новости с логотипами; трек из `_бренд/музыка`), плашки/вырезки/выноски (`graphics/overlays`). Прозрачные слои → ProRes 4444 на Mac (VP9-alpha webm → `prores_ks -profile:v 4444`).
7. **Финал**: сначала `python3 pipeline/speed.py edl.json words.json` (авто-ускорение ×1.10–1.15, пересчитывает rec; specs_build.s2r = rec + (t − src_in)/speed), потом specs (вместо старой карточки `end` — `outro` на 5 с сразу после последнего слова: `G('outro','outro', E['total']+0.2, 5.0, day=N)`; у каждой перебивки type `kicker` — на ней звучит sfx), затем `python3 pipeline/mac_final.py …` — в папку задания положить `graphics/audio/sfx.wav` (сейчас каретка, вариант Антона подставить сюда) и `outro.wav`. Задание `~/PokaTySpal/queue` (см. «Рендер на Mac») собирает `05_публикация/…_FINAL.mp4` (интро, куски, плашки, −14 LUFS). FCPXML для DaVinci — только по просьбе (DaVinci не читает альфу наших ProRes 4444 — проверено 03.11).
8. **Шортсы/Reels** (не больше 3 в день, см. «Решения 04.11»): если в `02_сценарий/scenario.md` есть пометки `[SHORT N | хук: … ] … [/SHORT N]` — шортсы режутся по ним (хук = текст первого кадра), иначе выбираешь сам; вертикальный кроп 1215×2160 → 1080×1920 + оверлей с логотипами на первом кадре, хуком и словесными субтитрами (graphics/overlays/shorts.html), рендер ffmpeg на Mac.
9. **Проверка**: `pipeline/qa.py` по ФИНАЛЬНОМУ файлу + кадры финала глазами (лицо видно вокруг плашек) → `04_монтаж/qa.txt`. С замечаниями не сдавать.
10. **Публикация**: главы из edl → `chapters.txt`; превью A/B (`graphics/overlays/thumbnail.html`); тексты — Claude (Gemini убран 03.11): 3 названия и 3 превью для A/B-теста, обложки шортсов по ТЗ из сценария (лицо — из библиотеки эмоций). Отдать Антону: таймлайн, шортсы, превью, тексты — одним сообщением, всё сразу.
11. Закоммитить `episodes/ГГГГ-ММ-ДД/` (takes, edl, specs, shorts, publish, transcript).

## Reels / Shorts (Toxic TV и нарезки)
- Тон и бренд: Toxic TV — чёрный + кислотно-розовый #FF2E93 + вольт #E8FF2E, штампы, «7 vs 18», капс-субтитры (graphics/overlays/toxic_reels.html). Новостные шортсы — бренд «Пока ты спал» (graphics/overlays/shorts.html).
- Порядок: `takes.json` на каждый ролик → `CUT_GAP=0.22 CUT_PAD=0.07 python3 pipeline/cut.py …` → **сверка** `pipeline/review.py … --audio` (см. 5a, сам, без «ок» Антона) → `reels_config.json` (заголовок, штампы, списки, vs в секундах исходника) → `python3 pipeline/reels.py` → рендер графики (`TPL=toxic_reels.html node graphics/overlays/render_vertical.js`) → VP9-alpha → B-roll из Pixabay на окна `covers` → `python3 pipeline/vertical_render.py … > render.sh` → на Mac `bash render.sh 1`, `2`, `3` (каждый шаг < 180 с; шаг 1 можно повторять — готовые куски пропускаются).
- Финальная карточка не перекрывает речь: `tail` в reels_config (стоп-кадр после последнего слова, = endDur). Части на Mac называются по содержимому (`p_<src_in>_<кадры>_<scale>.mov`) — после правки монтажа перерендериваются только изменённые куски.
- Куски рендерятся по одному с точной длиной звука (PCM + apad + -t), иначе звук уезжает; несколько 4K-декодеров сразу VM убивает.

## Решения Антона 05.11 (действуют с 06.11)
- Сценарий из трёх блоков (docs/SCENARIO.md v3): 1) новости ТОП-10 на выбор (может не записываться); 2) ОБЯЗАТЕЛЬНО «Новости ИИ за 2 минуты» — шортс 5×20 с, без заставки, отбивки-номера, маленькая бегущая строка; 3) тест нового формата — «ТОП-3 стартапа/технологии» (~3 мин на каждый, основной канал) + познавательный шортс из самого удивительного.
- Шортсов ≤ 3: новости за 2 минуты + познавательный + (опционально) одна сильная история. Тизер 20 с больше не делаем. Банальные «попробуй сам» (гифки, «пришлите фото») — нет.
- Монтаж «Новостей за 2 минуты»: вертикальный кроп, субтитры ниже лица, отбивка с номером и заголовком между новостями (sfx каретки), бегущая строка внизу над зоной интерфейса, обложка с логотипами.
- Формат канала пересматриваем после первой недели: еженедельный дайджест + ежедневные короткие форматы.

## Решения Антона 04.11 (действуют с 05.11)
- **Шортсы: не больше 3 в день.** 1 — тизер всего выпуска (самые цепляющие фразы из 3–4 новостей + «полный выпуск на канале»); 1–2 — самые острые/вирусные новости. Публиковать с разносом по времени (шортсы одного канала конкурируют между собой).
- **Ускорение речи 1.10–1.15 автоматически** по темпу (слогов/с из words.json; цель — темп выпуска 04.11 на ×1.15; потолок 1.15 из-за моргания). Ускоряются только куски с ведущим (setpts+atempo по кускам), интро/плашки/бегущая строка/отбивка накладываются ПОСЛЕ, на обычной скорости; rec плашек пересчитываются. Выбранный темп сообщать при сверке.
- **Субтитры и текстовые плашки не на лице:** в выпуске — у нижнего края над бегущей строкой; в шортсах — ниже лица, выше зоны интерфейса YouTube (нижние ~15 %).
- **Звук перехода между новостями** (каретка печатной машинки / «дзинь» и т. п.) — Антон выбирает из 4–5 вариантов; кладётся на конец новости вместе с перебивкой.
- **Отбивка в конце 5 с:** после «До встречи» кадр уезжает (зеркально интро) → фирменный экран «Завтра в 06:00» + хвост трека. Без 15–20-секундной конечной заставки, пока нет видео для конечных элементов.
- **Шумоподавление:** запись 04.11 — фон −57 дБ при пиках > 0 дБ; после −14 LUFS шипение слышно. Добавить шумоподавление по профилю тишины первых 3 с (afftdn/arnndn) до loudnorm.
- **Источники:** в описании — первоисточники (блог компании, статья, GitHub, paper); X — только если первоисточник сам пост. Кандидаты не только из Grok/X: HN, GitHub Trending, Product Hunt, Hugging Face.
- **«Что сделать» не примитивное.** Новая рубрика в конце выпуска: одна вещь дня (скилл, плагин, MCP, репозиторий, сборка), которая сейчас у всех на слуху — что это и как поставить; из неё может быть прикладной шортс. Если вещь дня очень громкая — она 3-й шортс. Тест двух моделей через день: A — шортс даёт пользу целиком (показ + результат, промт в закреплённом комментарии); B — шортс показывает результат, «как поставить и промт — в выпуске», связь через «Связанное видео» в Shorts. QR-коды не использовать. Через ~2 недели сравнить просмотры шортса и переходы в выпуск (Analytics). Название/уровень/подача рубрики — ждём ответа Антона.
- **Пакет публикации одним сообщением:** видео → 2–3 названия → превью → описание с главами → **теги (всегда, без запроса)** → закреплённый комментарий → шортсы с названиями и тегами. Главы — по итоговому (ускоренному) таймлайну.
- **Хранение:** единственное место — Drive `выпуски/ГГГГ-ММ-ДД/` (`03_запись` = исходник, `05_публикация` = всё готовое). Загрузки не использовать. Перед рендером проверять свободное место (нужно ≥ 30 ГБ; меньше — сразу написать Антону, не падать посреди рендера). После «выложил» (с согласия Антона): удалить `~/PokaTySpal/jobs/<дата>` и `out/*`, снять «Доступно офлайн» с исходника. Битые куски (без moov) проверять ffprobe перед склейкой.
- **Обложки шортсов и превью выпуска — ВСЕГДА с логотипами компаний из истории** (Claude, OpenAI, Gemini, Notion… — graphics/node_modules/@lobehub/icons-static-svg/icons; белые плашки). Обложки шортсов делать сразу вместе с шортсами (shorts_cover.html), без запроса.
- mac_final.py: имена кусков без индекса (`p_<src_in>_<кадры>_<scale>.mov`), чтобы правка монтажа не вызывала перерендер; финал по умолчанию 4K.
