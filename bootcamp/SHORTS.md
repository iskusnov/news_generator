# Шортсы из уроков буткемпа — процесс (финал 12.11.2026)

Образцы финала: `bootcamp/2026-10-27/shorts_final/` (Даниил Пилипенко, «Декомпозиция») и `bootcamp/2026-11-10/shorts_final/` (Николай Барышников, «Мультиагенты»: `planf.py`, `buildf.py`, `scenesf.py`).
Итог на Drive: `<папка урока>/05_готово/шортсы_финал/` — 10 роликов «NN Заголовок-вопрос.mp4» + `список_шортсов.md` (заголовок, длительность, хук).

## Что решил Антон (12.11) — правила
1. **Хук проверить первым делом.** Прочитать первые 3–5 с каждого ролика. «Дальше мы…», «То есть…», «поэтому…», «вот,» — это не хук.
2. **Хук = сочная фраза лектора в ноль** (вариант Б). Самая цепляющая фраза из этого же ролика (3–7 с: парадокс, цифра, боль, вопрос залу) ставится первым куском (`tag: hook`), дальше ролик как был. Повтор фразы в теле допустим как «возврат».
   Вариант А (тёмная карточка-вопрос на весь кадр 2 с без звука речи) протестирован и **не зашёл**: много текста, тяжело читать. В шаблоне остался (`spec.hookcard`, кусок `mute` в edl), но не используем.
3. **Кинетика хука — 2–3 короткие строки**, каждая появляется под слово лектора (время строки = время слова в субтитрах) с «попом»; на 0 с — тихий «вжух». Звуки: `graphics/audio/sfx_pop.wav`, `sfx_whoosh.wav`, в spec — `sfx:[{file,at,vol}]`.
4. **Заголовок сверху — вопрос, не ответ** («500 агентов: в какой ресурс мы упрёмся?», а не «первым откажет диск»). Слева, по верхнему краю.
5. **Шапка справа:** синяя плашка «Разработка» (цвет направления, `--dev #3446D3`), под ней тема урока одним словом (`tag`: «Декомпозиция», «Мультиагенты»). Без номера урока, без «Нэйшн» и сайта наверху.
6. **Подпись лектора — крупно, в две строки:** имя (36 px) и компания (22 px) — по сайту ai-nation.ru (Барышников — ex-Yandex Cloud; Пилипенко — SymbioWay). «Разработка» под именем не писать.
7. **Водяной знак весь ролик:** «Нэйшн · ai-nation.ru» полупрозрачно у нижнего края (y≈1828), под субтитрами.
8. **Концовка:** «Нэйшн / Технари новой формации / Больше у нас в Telegram-канале — ссылка в профиле».
9. **1-секундную брендовую заставку в начале шортса не ставим** — теряем удержание первой секунды; бренд виден с первого кадра.
10. **Тексты — только сказанное лектором**, его лексика (код-мод → code mode, гардрейл → guardrail, «модельке доверять нельзя»). Никаких «сэкономит недели» от себя.

## Шаги
1. **Выбор 10 кусков** (40–65 с): яркие мысли, полезные разработчику; только где говорит лектор (камера avo показывает его). `plan.py`: фразы начала/конца → `wtools.seg()` (`find` ищет ±120 с от подсказки — подсказку брать точную, иначе находит другое вхождение).
2. **Хук-аудит** (правило 1) → в план первым куском фраза-хук (`planf.py`, словарь `HK`). Вялое вступление можно просто отрезать (03 у 27.10).
3. `CUT_GAP=0.22 CUT_PAD=0.07 python3 pipeline/cut.py takes.json words.json silence.json - edl.json` → `pipeline/review.py` (ОБРЫВ/ПОВТОР; риторические повторы лектора не трогаем).
   Края кусков проверять по огибающей звука (ffmpeg → RMS по 20–40 мс на Mac): Whisper склеивает слова («хорошим. После» без паузы, «то есть» длиной 0,02 с) — резать в провале огибающей.
4. **Субтитры** (`buildf.py`): `reels.py` даёт базу, потом слова берутся **только из запланированных фраз** с допуском 0,1 с на границе (Whisper даёт словам соседних кусков перекрывающиеся тайминги → слова теряются/дублируются). Для куска-хука — только слова хук-фразы. Правки распознавания — `replace` в reels_config (селя→shell, код-мода→code mode, P→Pi, промп→промпт…). Первое слово — с заглавной.
5. **Карточка участника в камере Zoom:** avo иногда показывает не лектора («Sergey Ivanov»). Найти по `avo_tiny.mp4` (2 к/с, 96×54) — доля серого > 0,85. В edl у куска `cam_ss` — сдвиг камеры в секундах (звук на месте), кусок разбить по границе слова.
6. **Моушн-сцены** (`scenesf.py`, шаблон `graphics/overlays/nation_motion.html` из `make_nation_motion.py`): kinetic (хук), stage (ic/tx/pill/card/ln/mk/dt), steps (≤ 4 пункта, текст пункта в одну строку — иначе заголовок шагов уезжает под камеру), nodes. Время — `T(sid, 'фраза', after)` по словам субтитров; токены с пробелом («dark factory», «code mode») ищутся слитно (`darkfactory`). Сцены встык, без пустой панели. Подписи nodes центрируются по x; не ставить подпись над узлом ближе 200 px.
   Перенос старых сцен на новый монтаж (после вставки хука): время старого ролика → исходник → новое время по кускам после хука (`build3.py`/`build4.py` в `2026-10-27/`).
7. **Факт-чек сцен** — отдельным агентом (`bootcamp/README.md` 5a).
8. **Оверлеи:** `ONLY=id TPL=nation_motion.html node graphics/overlays/render_vertical.js specs_motion.json pngm` параллельно **по 5** (10 сразу — иногда один процесс молча падает: проверить, что в логе 10 строк `webm`) → VP9-alpha (`runm.sh`). ~25 к/с на процесс.
9. **Рендер на Mac:** `LESSON=1 MOTION=1 CAMY=260 BGC=0xF6F5F1 CAM=avo AUD=m4a vertical_render.py edl spec экран.mp4 ovm.webm <папка задания со sfx> out.mp4 > rm_id.sh`; задание `job.sh` (шаги 1/2/3 на каждый ролик) → `~/PokaTySpal/queue`. Куски кэшируются по имени `p_<src_in>_<кадры>_<scale>[_c<cam_ss>][_m].mov` в `~/vrtmp/<имя выхода>` — **разные раскладки (слайд/моушн) — разные имена выхода** (иначе возьмёт куски чужой раскладки). 10 роликов ≈ 5–10 мин.
   Служба рендера не пишет в CloudStorage (TCC) — на Drive копировать через мост (`device_bash cp`) после `FINAL_OK`.
10. **Проверка:** длительности = spec.dur; кадры финала глазами (хук, середина, камера в окне карточки); громкость «попов».
