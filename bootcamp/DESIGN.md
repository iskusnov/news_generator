Статус: **временная**. Ориентир — ai-nation.ru (светлый сайт) и раздел буткемпа ai-nation.ru/dev. Решение Антона 06.11:
дизайн-системы у Nation нет, сайт светлый, не чёрный; выноски полупрозрачнее; нужно больше графических элементов, а не «скупые плашки».
v1 (тёмная, 06.11 утро) отклонена: слишком темно, плашки на чёрном закрывают пол-лица.
Когда появится бренд-бук буткемпа — заменить токены в `graphics/overlays/bootcamp.html` (`:root`), компоненты оставить.

Шаблон: `graphics/overlays/bootcamp.html` (API `setup/seek`, как у `template.html`), иконки — `icons_boot.js` (lucide-static, инлайн SVG:
CSS-маски с file:// не грузятся). Рендер: `SCALE=1 TPL=bootcamp.html node graphics/overlays/render.js specs.json outdir` → PNG →
VP9-alpha (`ffmpeg -c:v libvpx-vp9 -pix_fmt yuva420p -auto-alt-ref 0`). Превью на кадре урока: `--preview` (фон `overlays/bg_boot.jpg`).
specs из плана урока: `python3 bootcamp/build_specs.py graphics_plan.json edl.json specs.json` (время исходника → итоговое видео, разнос наложений).

Мотивы: логотип «НЭЙШН >>», служебная строка `[bootcamp_03] // AI >> NATIVE DEVELOPER`, янтарные угловые скобки на карточках,
сетка-«чертёж» и точечный паттерн на полноэкранных картах, бегущая янтарная строка, шевроны `>>`.

**Почему почти непрозрачные карточки:** слайды лекторов плотные — полупрозрачная карточка поверх текста слайда не читается (проверено на уроке 05.11).
Тема `glass` — для моментов, когда в кадре камера, а не слайд.

## Раскладка кадра 1920×1080
- Основная картинка — демонстрация экрана Zoom. Zoom сам вшивает окно камеры **320×180 справа сверху (x 1600–1920, y 0–180)** —
  поверх него ставим чистую камеру лектора из avo **384×216**, янтарная кромка 3 px слева и снизу (`pipeline/mac_lesson.py`).
- Без демонстрации (Zoom пишет камеру на весь кадр) PiP выключается: интервалы ищутся по прокси (корреляция кадров экрана и avo > 0,6) → `noshare.json`.
- Нижний левый угол (отступ 72 px) — одна плашка за раз: глава, термин, цитата, вопрос. Справа под камерой (top 212) — цифра/схема.

|---|---|---|---|

| `term` | 7 с | термин при первом упоминании: иконка, слово, определение лектора | `word, def, icon, n` |

| `scheme` | 8–20 с | схема справа (`list` / `vs`) — только если слайд пустой | `kind, icon, label, head, items[] / a, b, at[]` |

| `hw` | 12 с | финал ДЗ (ставится ПОСЛЕ урока на стоп-кадре): задание, «что продумать/сдать», срок и куда — только если названы | `lesson, date, task, deliverLabel, deliver[], deadline?, where?` |
| `cam` | — | рамка + имя на окне камеры (не нужна, если avo уже с подписью Zoom) | `name, role` |

## Правила
- Тексты на графике — только из лекции/глоссария урока, ничего от себя. **Никаких «[уточнить]» в видео:** не названо — не выводим (Антон 06.11).
- Вопросы участников — без имён. Цифры — только те, что лектор сам посчитал правильно (Precision со слайда 05.11 — с ошибкой, не выводили).
- Анимации: вход 0,4–0,6 с (`power3/power4.out`), выход 0,35–0,45 с.
