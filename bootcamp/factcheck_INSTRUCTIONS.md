# Задача проверяющего: сверить тексты графики с речью лектора

Ты — независимый проверяющий. Графику делал другой человек; твоя задача — найти места, где текст на экране
НЕ совпадает по смыслу с тем, что сказал лектор (Михаил) или участники урока в записи.

Файл пачки содержит блоки: «На экране» (тексты, их тип, цвет, время появления в формате мин:сек исходной записи)
и «Речь» (транскрипт Whisper того же отрезка, с метками [мин:сек]). Транскрипт автоматический: в нём бывают ошибки
распознавания (например «рак» = RAG, «ЛЛМ/лэмка» = LLM, «ризонинг/резинг» = reasoning, «Ридми/Redmi» = README,
«байос» = bias, «пиар» = PR, «ICD» = CI). Это не ошибки графики.

Значение цвета: красный = «плохо / не работает / ошибка», зелёный = «хорошо / работает», ✓ / ✕ — то же самое.
Цвет и значки — это утверждение, его тоже проверяй (главная прошлая ошибка: на экране «плохо ищет: числа ✕, коды ✕»,
а лектор говорил, что с конкретными фрагментами — числами и кодами — эмбеддинг работает).

Для КАЖДОГО текста «На экране» вынеси вердикт:
- ok — по смыслу соответствует сказанному (пересказ и сокращение допустимы; заголовки-названия сцен и подписи
  к иконкам вроде «агент», «LLM», «спека» — ok, если не искажают);
- contradicts — смысл противоположный: инверсия «работает/не работает», «хорошо/плохо», ✓ вместо ✕ и наоборот,
  неверный цвет-оценка, перепутаны стороны сравнения;
- not_said — такого в речи нет (в этом окне и по смыслу урока), домыслено; иллюстративные примеры, которых лектор не
  приводил (выдуманные числа, слова-примеры), — тоже not_said;
- distorted — частично верно, но искажено: другая цифра, «иногда» стало «всегда», усилено/ослаблено, мнение
  участника подано как слова лектора или наоборот, неверно приписано;
- unclear — по этому окну нельзя решить.

Будь строг к contradicts / not_said / distorted — лучше лишний раз отметить. Но не придирайся к стилю и сокращениям.

Выход: JSON-массив в файл verdict_NN.json (NN — номер пачки) в той же папке, по одному объекту на КАЖДЫЙ текст:
{"id": "<id блока>", "text": "<текст на экране>", "verdict": "ok|contradicts|not_said|distorted|unclear",
 "evidence": "<короткая дословная цитата из речи, на которую опираешься, или пусто>",
 "note": "<1 фраза: в чём проблема; для ok — пусто>", "fix": "<для не-ok: как правильно написать, коротко>"}
Пиши файл через инструмент Write. В конце ответь одной строкой: сколько текстов, сколько не-ok.
