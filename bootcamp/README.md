## Шаги
Правило всего конвейера (решение Антона 04.11): **«ок» не ждём — решаешь сам и сдаёшь готовое**, в сдаче 3–5 строк «что решил сам».
Тяжёлое (ffmpeg по видео) — заданиями на Mac через службу `~/PokaTySpal/queue` (см. CLAUDE.md «Рендер на Mac»); перед рендером проверить ≥ 30 ГБ свободно.

### 1. Звук → слова (≈ 5 мин, без токенов) — заданием на Mac
- Задание в `~/PokaTySpal/queue` (образец — `jobs/boot1105/b1_*.sh`, `b3_*.sh`): `ffmpeg -vn -ac 1 -ar 16000 -c:a aac -b:a 48k` → `signals.py audio.m4a silence.json` и `signals.py audio.m4a silence_cut.json -35 1.2` → `groq_words.py audio.m4a silence.json 0 words.json --key <файл ключа>`. Ключ читается на Mac, в чат не попадает.
- Ключ: `~/Downloads/transcribe/.groq_key_claude`. **06.11:** macOS (TCC) временно не пускал службу в «Загрузки» — задание проверяет `[ -r ключ ]` и берёт запасной `~/PokaTySpal/.groq_key_claude`.
- `groq_words.py` (06.11): галлюцинации-фразы («Продолжение следует…») выкидываются по сегментам, а не по словам.
- Прокси для взгляда: экран 1 кадр/с 480p, камера 320p (задание `b2_proxy`).

### 2. Транскрипт со спикерами и таймкодами (≈ 100 тыс. токенов)
Сырой текст: `python3 pipeline/transcript_tools.py words words.json zoom.vtt raw.md names.json` — абзацы по паузам, таймкоды из слов Groq, спикеры по времени реплик .vtt (точнее выравнивания текста). Чистовик — частями по ~24 тыс. знаков. По схеме скилла meeting-transcript: имена из `.vtt` Zoom (текст Zoom — только для имён), чистовик одним потоком: убрать паразиты/повторы/галлюцинации Whisper, ошибки распознавания править по контексту, неясное — `[неразборчиво]`, имена — `[?]`; заголовки `##` по темам; таймкоды `` `ЧЧ:ММ:СС` `` у каждого абзаца.

### 3. Текстовые материалы (≈ 100 тыс. токенов + проверка)
Только то, что прозвучало на уроке, **ничего от себя**. Формат — как в `bootcamp/2026-10-23/`:
- **Лекция** (~8–10 тыс. слов из ~17 тыс.): шапка (тема, дата, длительность, ссылка на видео), оглавление с таймкодами, части → подразделы с ▶ таймкодом; устное («поставьте сердечко», орг-моменты, повторы) убрать; вопросы участников **без имён** врезками «Вопрос из зала/из чата → Ответ»; споры — короткая сводка мнений + вывод лектора; оговорки помечать, не исправлять.
- **Файл для нейросети** (.md, ~100 КБ): инструкция «отвечай только по этому тексту, иначе скажи, что ответа нет» → паспорт урока → ключевые тезисы с таймкодами → термины в формулировке лектора → Q&A → полная лекция → ДЗ.
- **ДЗ**: цель, условие словами лектора, что сдать, формат, как проверят, срок (не назван — `[уточнить]`), таймкод объяснения.
- **Проверка на выдумки — отдельным агентом** (не тем, что писал): сверить каждый файл с транскриптом (факты, цифры, примеры, кому принадлежит реплика, таймкоды, «наверное/желательно» лектора). Найденное исправить.
- Таймкоды ▶ в лекции/ДЗ/ИИ-файле — по ИТОГОВОМУ видео: пишем по исходнику, потом `python3 pipeline/lesson_edl.py tc edl.json <пре-ролл_с> in.md out.md`. Транскрипт остаётся в времени исходника.
- Лекция и ДЗ → Google Docs в папку урока (Drive-коннектор `create_file`, `contentMimeType: text/markdown` — Markdown конвертируется в Doc), `.md` → в `05_готово/`.
- ДЗ: срок/формат/проверку — только если названы на уроке; не названо — не пишем, без «[уточнить]» (срок ставят в LMS).

### 4. Монтажный лист «что вырезать» (≈ 30–40 тыс. токенов, паузы режет код)
Образец: `bootcamp/2026-10-23/montazh_list_urok_2026-10-23.csv` (№ · тип · с · по · сек · конец фразы до · начало фразы после · причина).
- **Паузы**: тишина > 1,2 с (−35 дБ) → оставить 0,5 с. На уроке 23.10: 309 пауз, 9,4 мин.
- **Смысловые** (решаешь сам по транскрипту): ожидание до начала, разогрев «никого не вижу / поставьте сердечко», технические заминки («нельзя выбрать», «слышно?»), прощания после «всем пока». Содержание (объяснения, вопросы и ответы) **не режем** — урок нужен полным.
- Код: `python3 pipeline/lesson_edl.py silence_cut.json words.json semantic.json <длит_с> edl.json montazh.csv` (semantic.json — смысловые вырезки [{from,to,why}]). Пауза режется по звуку; пропускается, только если в неё целиком попало слово (края слов Whisper «размазывает» на тишину).
- Итог 05.11: 3:06:33 → 2:48:44 (215 пауз 6,8 мин + 4 смысловых 11 мин: начало, два перерыва по 5 мин, прощание).
- Итог 23.10: 2:53:09 → 2:41:08.

### 5. Графика — урок «как записанный аккуратно» (главное отличие от простой чистки)
Проблема: на слайдах лектора часто только заголовок и пустота, участники без камеры — чёрная плашка. Графика возвращает уроку наглядность. **Тексты — только из лекции/глоссария урока.**
1. **Пре-ролл 5–7 с**: «Буткемп · 3 поток · Урок N · <тема> · <лектор> · <дата>».
2. **Заставки глав** (по оглавлению лекции): короткая плашка «1.4 · Механизм внимания».
3. **Слайды/схемы motion-дизайном** там, где лектор объясняет, а на экране пусто: экран делится — лектор/демонстрация слева, схема справа (пример 23.10: пространство смыслов, «слон и золотые рыбки», список ревьюеров, два условия качества).
4. **Выноски терминов** внизу при первом упоминании (определение лектора из глоссария).
5. **Карточки вопросов**: когда говорит участник без камеры — «Вопрос из зала: …» вместо чёрного экрана.
6. **Цитаты-акценты**: яркие фразы лектора крупно (как в роликах интервью).
7. **Финал**: экран ДЗ (условие, что сдать, куда) + «Текстовая версия и файл для нейросети — на странице урока».
- Картинка: основная — демонстрация экрана 1920×1080; камера лектора (avo) — картинка-в-картинке в углу; когда экран без демонстрации — камера на весь кадр.
- Стиль и компоненты: **`bootcamp/DESIGN.md`** (временная дизайн-система v2, светлая, по ai-nation.ru; шаблон `graphics/overlays/bootcamp.html`).
- План графики урока — `graphics_plan.json` (время исходника; тексты только из лекции) → `python3 bootcamp/build_specs.py graphics_plan.json edl.json specs.json` → `SCALE=1 TPL=bootcamp.html node graphics/overlays/render.js specs.json png/` → VP9-alpha → на Mac в `render/gfx/` (через `device_commit_files` по файлам; .tar коммит не принимает).
- 05.11: схемы справа не ставили — слайды лектора плотные; главное — главы с картой урока, термины, цитаты, вопросы, цифры.

### 5a. Факт-чек графики (обязательно, решение Антона 06.11)
Всё, что на экране (живые слайды, плашки, сцены шортсов, заголовки; цвет и ✓/✕ — тоже утверждение), сверяется с речью:
`python3 pipeline/gfx_factcheck.py extract words.json fc --lesson graphics_plan.json edl.json --shorts shorts/` → items.json, mech.json
(цитаты дословно, цифры в речи, не раньше слов) и batch_NN.md → каждую пачку проверяет **отдельный агент** (не автор графики) по
`fc/INSTRUCTIONS.md` → verdict_NN.json → `gfx_factcheck.py report fc` → report.md. Код 3 (есть «противоречит»/«не говорилось») — рендер не запускать.
Запуск: после написания сцен (до рендера) и по финальной графике перед сдачей. Урок 23.10: 591 текст, 27 замечаний (2 противоречия цвета, 4 домысла).

## Шортсы из урока (с 06.11, образец — `bootcamp/2026-11-05/shorts/`)
10 вертикальных роликов по 40–60 с из одного урока — на выбор команде канала; кладутся в `05_готово/шортсы/` с человеческими именами + `список_шортсов.md` (о чём, длительность, откуда).
1. Выбор: яркие мысли лектора, полезные разработчику (миф → правда, ловушки, личный опыт, принципы); только куски, где говорит лектор (avo показывает говорящего).
2. `plan.json` (id, заголовок-хук с `<b>акцентом</b>`, сегменты фразами) → takes по словам: конец куска — на слове с точкой/запятой и до начала следующего слова (иначе в звук попадает начало следующего).
3. `CUT_GAP=0.22 CUT_PAD=0.07 pipeline/cut.py takes words silence - edl` → `review.py` (повторы у лектора чаще риторические; вырезаем только реальные оговорки) → `reels.py reels_config.json` (replace: «рак»→RAG, «ЛМК/лэмка»→LLM, «имбеддинг»→эмбеддинг) → `bootcamp/subfix.py subfix.json .` (правка фраз субтитров, удаление «хвостовых» слов Whisper).
4. Оверлей: `TPL=bootcamp_short.html node graphics/overlays/render_vertical.js specs.json png/` → VP9-alpha. Кадр: заголовок, камера лектора 1080×608 (y 280) с подписью, слайд 1080×608 (y 904; окно камеры Zoom закрыто плашкой «слайд урока»), субтитры y 1528 (выше интерфейса Shorts), финальная карточка «Подписывайся».
**Хук — проверить первым делом (Антон, 12.11).** До рендера прочитать первые 3–5 с каждого ролика: если лектор начинает с «Дальше мы…», «То есть…», «поэтому…» — это не хук. Тогда холодный старт: самая цепляющая фраза лектора из этого же ролика (3–7 с; вопрос, цифра, неожиданный вывод) ставится первым куском (tag `hook`), дальше ролик как был; в теле её можно оставить как «возврат» или убрать, если повтор > 5 с. Хорошо работает вопрос лектора к залу («Как вы думаете…?»).
**Заголовок сверху — вопрос, не ответ** («500 агентов: в какой ресурс мы упрёмся?», а не «первым откажет диск»).
**Шапка/подписи (финал 12.11):** заголовок-вопрос слева по верхнему краю; справа плашки «Разработка» (синяя, --dev) и под ней тема урока; под камерой имя (крупно) и компания второй строкой (Барышников — ex-Yandex Cloud, Пилипенко — SymbioWay); внизу у края полупрозрачный «Нэйшн · ai-nation.ru» весь ролик. Хук — вариант Б: сочная фраза лектора в ноль + 2–3 короткие строки кинетики под голос с «попом» (sfx_pop/sfx_whoosh в spec.sfx). Карточки-вопросы (вариант А) Антону не зашли. Заставка урока — intro_v3.html вариант tri: лектор ↔ AI Bootcamp ↔ 6 плиток ключевых тем урока (сверять с лекцией независимой проверкой).
**Карточка участника в камере Zoom** (avo показал не лектора): в edl у куска `cam_ss` — сдвиг камеры в секундах, звук на месте (vertical_render.py).
5. Рендер на Mac: `LESSON=1 CAM=avo.mp4 AUD=звук.m4a pipeline/vertical_render.py edl spec экран.mp4 ov.webm - out.mp4` — все 10 одним заданием ≈ 3 мин; −14 LUFS. Переименовывать в папке Drive — через мост (`device_bash mv`), служба получает «Operation not permitted».
